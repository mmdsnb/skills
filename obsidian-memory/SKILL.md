# 长期记忆

## 读：先假定忘了

任何可能依赖既有事实的问题，先检索再回答：

```sh
rg -l --glob '*.md' --glob '!00 Inbox/**' --glob '!40 Archive/**' '<实体名|主机名|服务名|别名>' ~/obsidian-second-brain
```

- 换 2–3 组关键词，全称与简称都试；
- 日记不参与知识检索；只有用户明确提到某个日期或「当天」时才去 `00 Inbox/日记/` 读；
- 命中后读全文，不看片段下结论；
- 只顺着正文的 `[[链接]]` 读关联笔记，不批量扫目录；
- 回答开头写「据 vault：<笔记名>」；没有就明说「vault 无记录」，不拿本地残留冒充。

## 写：提议后才动手

触发：用户要求沉淀；或收尾时出现已验证的配置/决策、被纠正的旧事实、新资产上线、旧方案下线、可复用 SOP。

五条全满足才提议，否则沉默：半年后仍有效、下次可复用、已确认、检索后无重复、不含凭据。

写入流程：`git pull --rebase --autostash` → 改对应文件 → 更新 `updated` → 提交推送：

```sh
cd ~/obsidian-second-brain
git add -- "<文件>" && git commit -m "memory: <动作> <实体>" && git push
```

- 一实体一笔记；旧值直接覆盖，不堆修订记录（git 就是历史）；
- push 被拒：`git pull --rebase --autostash` 后重试一次；冲突则 `git rebase --abort` 并报告，不自行合并。

## 结构（PARA + 编号）

| 目录 | 内容 |
| --- | --- |
| `00 Inbox` | 未整理的捕获；日记为 `00 Inbox/日记/YYYY-MM-DD.md`，只增不改 |
| `10 Projects` | 有明确终点的工作 |
| `20 Areas/21 环境与资产` | 机器、网络、账号、服务 |
| `20 Areas/22 规则与偏好` | 习惯、约定、SOP |
| `30 Resources/31 领域与知识` | 知识、资料、复盘 |
| `40 Archive` | 已结束或过时 |

日记不当作知识存放：复盘时把待办归到 Projects、参考资料抽到 Resources、长期事实抽到 Areas，日记里留 `[[链接]]` 备查。

不新建一级目录；新二级目录按编号顺延，先问用户。

## 笔记结构：金字塔原理

每篇笔记是一页速查，不是资料堆积。按金字塔原理（Minto Pyramid / BLUF）组织：

- 结论先行：标题下先给一句话现状或结论，再展开。
- 归类分组：事实按主题分组，组间互斥、组内穷尽，组名直接作 `##` 标题。
- 以上统下：标题概括其下内容，每组第一句仍是该组的结论。
- 逻辑递进：按使用时的查找顺序排（是什么 → 怎么用 → 坑 → 依据），不按记录时间。

Obsidian 的大纲与折叠只认 heading，据此约束渲染：

- 结构只用 `##` / `###`，不用加粗行冒充标题；列表最多两层。
- 表格、代码块、mermaid 顶格写，不缩进进列表。
- 一条列表只讲一件事，超过两行就拆条或改表格。

按内容的用途选载体，不全写成列表：

| 内容 | 载体 |
| --- | --- |
| 要复制执行的命令 | 代码块，句中不夹命令 |
| 同类并列事实（路径、端口、错误码、通道、实测对照） | 表格 |
| 推荐做法、解法 | `> [!tip] <一句结论>` |
| 坑、限制、不可逆操作 | `> [!warning] <一句结论>` |
| 普通事实 | 列表，开头用 `**标签**：` 点明主题 |

行内代码只留给文件名、配置键、字段名这类短词。

颜色由 vault 的 `.obsidian/snippets/cjk-reading.css` 与 Obsidian 内置 callout 提供，只作用于上表这些标准元素；不写 HTML、内联 style、`cssclasses` 或自定义 class 来上色。

## 笔记格式

按 `90 Meta/模板/实体笔记.md`：frontmatter 只有 `title` 与 `updated`，没有查询用途的字段不写；正文按上一节分组，一行一条当前值。

文件名不得含 `/ \ : * ? " < > |`（Windows 端会打不开），用全角 `／` 等替代；`[[链接]]` 的目标必须与磁盘文件名完全一致，不能写回原标题。

## 异常

- vault 或 git 缺失：停止并确认路径，不写到别处；
- 用户坚持有记录但检索无命中：换关键词再搜一次，仍无则报「vault 无记录」。
