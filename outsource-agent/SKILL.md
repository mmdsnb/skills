# Outsource Agent

后端看不到当前对话；工具只有 Glob/Read，只读、不能改文件。目录缺省为空临时目录。

## 调用

将 `<skill_dir>` 替换为本技能实际绝对目录：

```sh
uv run --script "<skill_dir>/scripts/outsource_agent.py" run \
  --dir ./iaa-images --timeout 600 \
  --task "逐个检查目录内所有 png，按文件名输出是否合格和原因，不要遗漏。"
```

| 参数 | 说明 |
|---|---|
| `--task, -t <文本>` | 任务全文；传 `-` 从 stdin 读取 |
| `--dir <目录>` | 后端工作目录；缺省为空临时目录 |
| `--timeout <秒>` | 超时，默认 180 |
| `--json` | 输出 `{ok, backend, elapsed_sec, result, error}` |

## 规则

- 输入放目录里，用 `--dir` 指过去；不要把文件内容读进主上下文。
- 任务写全：目录范围、文件匹配、排序、输出格式、不要遗漏。
- 输出格式敏感时写死格式，例如「只输出 JSON，不要代码围栏」。
- 结果当作初稿：关键结论抽查核对。
- 上千个文件分批跑，单批几百以内，每批一个子目录。

## 结果处理

- 退出码 `0`：stdout 即最终答案。
- 退出码 `2`：参数或目录错误，修正后重试。
- 退出码 `1` / `124`（失败/超时）：不要原样重试；拆小任务或自己处理。
- 报错提示命令不存在或认证失败：停止外包，告知用户，配置见 `references/backends.md`。
